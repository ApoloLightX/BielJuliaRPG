# Julia App v1

Aplicativo Android local-first feito para Julia.

- Sem login
- Tela BEM-VINDA, JULIA
- Frases motivacionais do Gabriel
- Grade semanal cadastrada
- Presença/falta por aula
- Frequência baseada nas aulas registradas
- Importação e reabertura de PDFs pelo seletor nativo Android
- Caderno por disciplina
- Layout responsivo para celular e tablet

A frequência desta versão é apenas um acompanhamento com base nos registros locais. O limite oficial de faltas depende da carga horária/créditos, ainda não informados.
