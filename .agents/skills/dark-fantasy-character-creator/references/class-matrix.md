# Class Matrix

This matrix describes the visual identity that customization should preserve. Gameplay values remain defined by `src/data/archetypes.js`; this document does not override them.

## Lâmina de Cinzas

- ID: `lamina-cinzas`
- Role: Guerreira
- Core silhouette: agile armored swordswoman
- Signature materials: dark steel, ash cloth, ember edge
- Default palette: Brasa
- Current weapons: espada longa, duas lâminas, montante
- Outfit direction: fitted battle layers, medium/heavy armor variants, damaged ceremonial details
- FX: embers, ash drift, heated edge
- Preserve: visible blade identity and aggressive forward-read silhouette
- Avoid: staff-first silhouette, giant guardian shield, bright holy-paladin language

## Shared customization

Safe shared options may include:
- skin tones;
- hair colors;
- face shapes;
- eye styles/colors;
- scars and non-class-exclusive markings;
- restrained jewelry;
- selected hair styles;
- neutral underlayers.

Class-specific options should include:
- signature armor;
- main weapons;
- class FX;
- class emblems/talismans;
- extreme silhouette pieces.

When a shared option weakens class recognition, make it class-specific instead.
